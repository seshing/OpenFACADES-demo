# OpenFACADES Demo

Interactive globe, Mapillary street views, detected facades and visually inferred building attributes.

Website: https://seshing.github.io/OpenFACADES-demo/
Project: https://github.com/seshing/OpenFACADES

## Update

Copy the updated contents of `OpenFACADES/demo/dist/` into this repository, then commit and push to `main`. GitHub Pages publishes the static files from the repository root. Keep `.nojekyll`.

Only precomputed results are displayed. Building attributes, ages and floor counts are visual estimates. Street-view image credits and source links appear in the viewer.

API keys, local processing scripts and caches are not included.
